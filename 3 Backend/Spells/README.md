# Compact Artificer Spells

These spell files were reduced to fields used by the current Character Builder and Character Sheet.

Kept:
- name, category, classes
- level, school
- casting_time, range, duration, concentration
- attack/save fields when applicable
- damage and damage_type when applicable
- ritual when applicable
- effect
- notes (components)

Removed:
- mode, shape, radius
- spellcasting_modifier
- dice_count/dice_size when `damage` already carries the displayed damage
- damage_bonus_stat/damage_bonus
- save_fail_chance/save_success_multiplier
- friendly_fire/requires_los
- utility_type/utility_value
- resource_cost/resource_formula

Copyright note:
The supplied Absorb Elements rules text was retained because it was provided directly in the conversation.
For the other spells, the existing concise paraphrased effect text is retained rather than reproducing
copyrighted rulebook descriptions in bulk.
